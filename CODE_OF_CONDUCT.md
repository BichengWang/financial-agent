# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep
discussion about the work. Harassment, personal attacks and discriminatory
language are not tolerated in issues, pull requests, reviews or any other
project space.

The maintainer, [@BichengWang](https://github.com/BichengWang), may edit or
remove comments and block contributors who break these rules. To report a
problem without posting publicly, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
tools, which go to GitHub Support.
